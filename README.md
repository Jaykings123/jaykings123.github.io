# Jay Viramgami Portfolio v2

AI/ML engineering portfolio built with React, Vite, GSAP, and GitHub Pages.

## Local Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Deployment

This branch is intended to deploy from `version-2` through GitHub Pages Actions.
The workflow builds the Vite app and publishes the `dist` folder.

To return to the old portfolio, switch GitHub Pages back to the `main` branch/source.
